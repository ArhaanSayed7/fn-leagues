# FDH v14.1.1 — Compact Discord Activity

## Changes

- Removed the large standalone Discord activity card from league pages.
- Added a small Discord activity pill directly beside the **Join Discord** button.
- The pill displays approximate total server members and currently online members.
- Added accessible hover text and labels explaining both values.
- Discord activity gracefully dims if the invite does not support server counts or the Discord API is unavailable.
- Preserved every feature from v14.1.

## Display

- People icon + total members
- Green status dot + online members

Discord counts are approximate and depend on a valid public Discord invite URL.
