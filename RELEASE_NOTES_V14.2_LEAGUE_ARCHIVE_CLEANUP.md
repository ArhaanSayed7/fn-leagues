# FDH v14.2 — League Archive & Cleanup

## Changes
- Completed race artwork now uses a consistent 16:9 frame with cover cropping.
- League pages show only the three most recently completed races.
- Added a compact, expandable full race archive for leagues with more than three completed races.
- Improved Discord online counts by using the guild widget count when available and bypassing browser cache.
- Added clearer labels to Discord member and online values.
- Removed Theme and Accent Colour controls from the league admin editor.
- Removed the Theme summary card from league pages.
- Cleaned up responsive league-page spacing and archive layouts.
